# Builder trials — collection plan

Status: no participants contacted, no feedback collected. This file is a trial protocol, not traction evidence.

## Initial target user

A launch creator or launchpad developer who chooses DBC parameters for a stock-quoted token. Recruit people who have made or are actively preparing that decision; general impressions from unrelated viewers do not establish demand.

## 15-minute observed task

1. Ask what launch they are planning and how they would currently choose supply, fee and curve settings. Record their own words with permission.
2. Give the product URL and ask them to compare two curves for an early-whale schedule, without explaining which one to prefer.
3. Ask them to identify one benefit and one cost of the long curve. Observe whether they notice endpoint-price and early-output-share differences.
4. Ask them to switch to sell pressure, explain reserve progress, and export a report.
5. Ask them to choose a configuration, share it and explain whether they would use the report in a real launch review. No funded transaction is required for this usability task.
6. Ask what they would do instead, what information is missing, and who else on their team would use the result.

## Evidence to retain

For each consenting participant: date, role, relevant experience, task completion, observed confusion, exact feedback, whether the report changed their selection, and any concrete follow-up they voluntarily agreed to. Distinguish a compliment from a usage commitment and a usage commitment from payment.

Do not create named testimonials, numbers or logos before actual permission and evidence exist. A synthetic persona is not a participant.

## Decision rules after the first 3–5 trials

- If users cannot explain the result: fix language and comparison controls before adding more models.
- If users understand it but would not use it: investigate their existing workflow and switching cost; do not call this validated demand.
- If a report changes a live configuration decision: document what changed and why, with the user's permission.
- If launchpad teams ask to embed it: prioritize an integration module over unrelated new protocols.

Outreach drafts can be prepared, but contacting anyone requires the user's explicit instruction.
